# Web Components Directory

This directory will house UI components implemented in Phase 5:
- `research/`: Research query input bar, search depth controls, model status pills.
- `drawer/`: Agent activity drawer (LangGraph live execution state, node milestones, search queries, processed URLs).
- `viewer/`: Document markdown viewer with KaTeX math rendering, syntax highlighting, and export controls.
- `citations/`: Interactive citation badge popovers displaying source URL, title, and exact extracted evidence snippets.
